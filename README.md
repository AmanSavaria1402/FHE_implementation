This repository contains my implementation of LWE based homomorphic encryption schemes and its basic operations, which I did to study and understand these schemes from a lower level. The code was written by following [Daniel Lowengrub's blog on FHE](https://www.daniellowengrub.com/blog/2024/01/03/fully-homomorphic-encryption), and thus you might find a lot of similarities in the code. My notes made during studying from this blog and the [TFHE-rs Handbook](https://github.com/zama-ai/tfhe-rs-handbook) can be found in this repo as well.
